# AWS Bastion Automation Lab

Linux automation scripts built in AWS using a bastion host, VS Code Remote SSH, and Bash.

## Included Scripts

- healthcheck.sh → hostname, user, IP, routes, disk, memory
- servicecheck.sh → checks sshd and docker service status
- remotecheck.sh → validates remote private instance access
- disk-check.sh → quick disk utilization check
- jump-private.sh → jump from bastion to private instance

## Environment

- AWS EC2 Bastion Host
- Amazon Linux
- Bash
- VS Code Remote SSH
- Private subnet connectivity

## Goal

Practice Linux administration, troubleshooting, and automation in an AWS environment.
